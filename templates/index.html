DATA PREPARATION

Import workbook

Choose inventory sheets, review the detected values, and resolve uncertain locations before anything is added.

1. Select a workbook and sheets

Single-sheet customer/freezer workbooks are selected automatically. Legacy workbooks can still import selected inventory sheets; EXPORT and SHIPMENT are optional.

2. Review and edit rows

Import rules

Source values are trimmed and whitespace-normalized only. Possible matches are suggestions, never silent corrections.

  • For customer/freezer sheets, Store Location is imported as Business Address, the unnamed region column as Area, AREA as Province, and FREEZER BRAND as Freezer Brand. Sales Rep is retained with the store; Manufacturer is left blank if the source has no separate manufacturer column.
  • Review each record in the editable row grid. Store and contact details, including Sales Rep, can be corrected per row; Area and Province selections stay linked to the approved hierarchy. Missing geography remains blank only after acknowledgment.
  • New Freezer Brand, Equipment description, Manufacturer, or Model values can be requested from a row and require administrator approval before the import is added. Repeated source values can be edited independently row by row.
  • Legacy inventory workbooks still show the original Store Location for clarification. Every accepted asset retains its source sheet and row, and its serial number remains individually searchable.

CONTROL CENTER

Administration

Manage accounts, controlled dropdowns, and review the activity log.

User accounts

Staff can manage equipment and service records. Admins can also manage users and lists.

Controlled lists

Add values, or edit an existing value and select “Save name” to update linked records. Deactivate redundant values to keep historical records intact.

Database backups

Automatic backups run daily at the selected server-local time while ColdTrack is running. The latest 30 backups stay on this host under instance\backups.

Download a backup to keep a copy off this host. Backup files contain the complete database, including account password hashes; keep them private.

Reset for testing

Deletes all stores, freezers, services, imports, logs, dropdown values, and other accounts. The signed-in administrator is retained. A database backup is created first.

Possible value variants

Suggestions only. Review before merging; a merge updates all matching equipment or service records.

Import values awaiting approval

Approve a proposed dropdown value before the related batch is added to inventory.

Activity log
